# Project Pembelajaran IP Address dan Subnetting

## 1. Deskripsi Project

Project ini membahas tentang IP Address dan Subnetting dalam jaringan komputer. Materi ini dibuat untuk mempelajari bagaimana perangkat komputer mendapatkan alamat IP dan bagaimana jaringan dibagi menjadi beberapa bagian yang lebih kecil.

Project ini merupakan bagian dari pembelajaran Teknik Komputer dan Jaringan (TKJ).

## 2. Tujuan Project

- Memahami pengertian IP Address.
- Mengenal jenis-jenis IP Address.
- Memahami kelas-kelas IP Address.
- Mengetahui fungsi Subnet Mask.
- Memahami konsep Subnetting.
- Mengetahui cara menentukan Network Address dan Broadcast Address.

## 3. Materi Pembahasan

1. Pengertian IP Address.
2. Jenis-Jenis IP Address.
3. Kelas IP Address.
4. Subnet Mask dan Prefix.
5. Pengertian Subnetting.
6. Network Address dan Broadcast Address.
7. Contoh Perhitungan Subnetting.

## 4. Manfaat Project

Project ini membantu siswa memahami dasar pengalamatan jaringan komputer dan melatih kemampuan menghitung pembagian jaringan menggunakan teknik Subnetting.

## 5. Kesimpulan

IP Address merupakan alamat yang digunakan untuk mengidentifikasi perangkat dalam jaringan komputer. Subnetting digunakan untuk membagi jaringan menjadi beberapa jaringan yang lebih kecil agar pengelolaan alamat IP menjadi lebih teratur dan efisien.
